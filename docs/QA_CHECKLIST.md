# قائمة اختبار يدوي على الآيفون (TestFlight)

علّم ✅ أو ❌ واكتب ملاحظة لأي خطأ (مع لقطة شاشة).

## 1. أول تشغيل
- [ ] شاشة الترحيب تظهر، وزر «العربية / English» يقلب اللغة والاتجاه فورًا
- [ ] «ابدأ الآن» ← «المتابعة على هذا الجهاز» ← التهيئة 7 خطوات تكتمل
- [ ] بعد التهيئة تفتح شاشة «اليوم» باسمك

## 2. اللغة والمظهر
- [ ] الإعدادات ← اللغة: عربي / إنجليزي / حسب النظام — كل الشاشات تنعكس صحيحًا
- [ ] المظهر: فاتح / داكن / حسب النظام — لا نص غير مقروء
- [ ] الأسهم والحلقات والجداول تنعكس في العربية

## 3. المهام والمنظِّم الذكي
- [ ] إضافة مهمة مرنة (30 د، عالية) ← تظهر في «غير مجدولة»
- [ ] الخطة ← «رتّب يومي» ← شاشة المراجعة تعرض الوقت الجديد ← «تطبيق»
- [ ] المهمة تظهر في الجدول اليومي والأسبوعي، ولا تقع على وقت النوم
- [ ] إضافة مهمة بوقت ثابت ← لا يحرّكها المنظِّم أبدًا
- [ ] تعليم كمكتملة ✓، التراجع، التأجيل للغد، «إيجاد وقت جديد»، الحذف مع «تراجع»
- [ ] مهمة متكررة يوميًا ← بعد إكمالها تظهر نسخة الغد
- [ ] مهمة بموعد نهائي مستحيل ← تبقى «بانتظار وقت» مع السبب

## 4. الالتزامات
- [ ] إضافة مناوبة ليلية (22:00 ← 06:00) ← تظهر على اليومين
- [ ] إضافة رحلة بمنطقة زمنية مختلفة ← يظهر الوقت المحلي والوقت بتوقيت الوجهة
- [ ] بعد الحفظ ← «مراجعة الخطة» ← المهام المتعارضة فقط تُنقل

## 5. العادات
- [ ] إضافة عادة من قالب، الضغط على «+» حتى الاكتمال، الاستمرارية تزيد
- [ ] عادة «أيام محددة» ← تظهر «غير مخططة اليوم» في الأيام الأخرى

## 6. التركيز
- [ ] بدء جلسة 15 د، إيقاف مؤقت، استئناف، إنهاء ← تظهر في السجل
- [ ] ربط جلسة بمهمة
- [ ] بدء جلسة ثم الخروج من التطبيق ← يصل إشعار عند انتهائها (بعد تفعيل الإشعارات)
- [ ] حظر التطبيقات ← يظهر بوضوح «غير متاح في هذه النسخة بعد» (قبل موافقة Apple)

## 7. النوم والتقارير
- [ ] تسجيل نوم الليلة الماضية ← يظهر في الرسم الأسبوعي والمتوسط
- [ ] التقارير تعرض أرقامك فقط، و«—» عند عدم وجود بيانات
- [ ] «نسخ بياناتي (JSON)» ← لصقها في الملاحظات يعرض بياناتك

## 8. الإشعارات والتقويم
- [ ] الإعدادات ← الإشعارات ← تفعيل ← نافذة إذن iOS تظهر
- [ ] تذكير قبل مهمة مجدولة يصل في وقته
- [ ] رفض الإذن ← يظهر زر «فتح إعدادات الآيفون»
- [ ] الإعدادات ← تقويم Apple ← نافذة الإذن **بالعربية** عند لغة الجهاز العربية
- [ ] مواعيد التقويم تظهر في الجدول، والمنظِّم لا يضع مهامًا فوقها

## 9. الحساب والمزامنة
- [ ] إنشاء حساب ← الدخول فورًا بدون بريد
- [ ] إضافة مهمة ← «تمت المزامنة»
- [ ] على جهاز ثانٍ (أو بعد حذف التطبيق وإعادة تثبيته): تسجيل الدخول ← البيانات ترجع
- [ ] وضع الطيران: إضافة مهمة ← «غير متصل» ← إعادة الاتصال ← تتزامن
- [ ] تسجيل الخروج ← البيانات تُزال من الجهاز
- [ ] حذف الحساب ← لا يمكن تسجيل الدخول به بعدها

## 10. عام
- [ ] لا يتجمد التطبيق ولا يُغلق فجأة في أي شاشة
- [ ] النصوص لا تُقص في الشاشات الصغيرة (iPhone SE) ولا مع تكبير الخط
